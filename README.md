# Career House Portal

School Website "Career House Schooling System" (Foundation)
- Homepage, About, Admissions Process, {Academics (Courses,Faculty, Gallery) according to Classes like Class 1,2,3,4}, Contact
- Website Chatbot for Answering fee, admission, timings FAQs instantly, 24/7
- Online admission inquiry form
- Fee structure page
- News & events section
- Mobile responsive + fast loading

School Info is provided in the ABOUT.md file
